## LD Manager 0.1.4

- **Automatic updates.** LD Manager now keeps itself up to date. Once a day it checks for a new version, downloads it in the background, and installs it when you quit or when it's idle in the menu bar. Every update must carry the project's signature. Turn it off in Settings › Software Update.
- **Problems looks like the rest of the app.** The Problems tab is a sortable table, with each problem's checks and fixes in the inspector. Dismissed problems appear with Show Dismissed.
- After an update, the privileged helper switches to the new version by itself.
